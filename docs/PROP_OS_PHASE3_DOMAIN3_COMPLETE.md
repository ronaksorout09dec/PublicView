### 3. Services with Business Logic & Edge Cases

**`InvoiceService`:**
- **createInvoice:** validates org, property/unit belong org, unit belongs property, tenant belongs org, lease belongs org if provided, billingPeriod start<=end, dueDate>=issueDate, at least one line item required, calculates subtotal sum qty*unitPrice, tax/discount, total = subtotal+tax-discount, generates invoiceNumber unique INV-YYYY-00001 atomic counter + uniqueness loop, saves DRAFT, saves line items, toResponse with daysOverdue computed ChronoUnit DAYS dueDate→today if status ISSUED/PARTIALLY/OVERDUE, balanceDue calculated
- **searchInvoices:** org + filters propertyId/unitId/tenantId/leaseId/status/type/search invoiceNumber LIKE
- **updateInvoice:** cannot update PAID/VOID/CANCELLED, partial fields, amountPaid overpayment allowed but logs warn (credit next invoice), auto status PAID if amountPaid >= total, PARTIALLY_PAID if >0, status transition validation DRAFT→ISSUED/CANCELLED, ISSUED→PAID/PARTIALLY/OVERDUE/CANCELLED, PARTIALLY→PAID/OVERDUE/CANCELLED, OVERDUE→PAID/PARTIALLY/CANCELLED, PAID/CANCELLED/VOID terminal, recalculates total if line items provided else subtotal+tax+late-discount, deletes old line items then saves new
- **deleteInvoice:** cannot delete PAID, soft delete
- **applyLateFee:** cannot apply to PAID/VOID/CANCELLED, calculates late fee via `calculateLateFee`: finds applicable rule property-specific first then org-wide, effectiveDays = daysOverdue - gracePeriodDays, if <=0 no fee, feeType FIXED=amountValue, PERCENTAGE_PER_DAY=totalAmount*rate%*effectiveDays, SLAB=amountValue*effectiveDays simplified, caps at maxCapAmount, returns 0 if no rule, updates lateFeeAmount, totalAmount, line item LATE_FEE add or update, status → OVERDUE if today>dueDate
- **autoGenerateRentInvoicesForMonth(monthDate):** YearMonth from monthDate, periodStart=1st, periodEnd=endOfMonth, issueDate=1st, dueDate=5th, finds all ACTIVE leases where start<=periodEnd and end>=periodStart (in-memory filter for Phase 3, later custom query), skips if invoice already exists for lease+period+RENT, **proration logic:** if lease.startDate after periodStart and same month → remainingDays = days between start and endOfMonth+1, ratio = remainingDays/daysInMonth, rent = lease.rent * ratio, description "Prorated rent for MONTH YEAR (remaining/total days, move-in date)". If lease.endDate before periodEnd and same month → occupiedDays = days between periodStart and endDate+1, ratio, prorated rent with move-out description. Creates InvoiceCreateRequest with single RENT line item, calls createInvoice, then marks autoGenerated true + status ISSUED. Returns count generated. Handles mid-month move-in/out edge.
- **generateInvoiceNumber:** INV-YYYY-XXXXX atomic + uniqueness check
- **toResponse:** line items, daysOverdue, overdue boolean, presigned PDF 30m, balanceDue fallback

**`LateFeeRuleService`:**
- **createRule:** org exists, property belongs org if provided, validates feeType requires amountValue or percentageRate, grace default 3, compounding default false, isActive default true, saves
- **getRules/getRule/update/delete:** org check, soft delete, duplicate name? Not enforced, but could

**`UtilityService` (Types, Meters, Readings, Bills, Splits):**
- **createUtilityType:** org exists, duplicate name per org blocked, name uppercased, saves
- **getUtilityTypes:** org scoped
- **createMeter:** org, property belongs org, unit belongs org if provided, utilityType belongs org, meterNumber unique, isShared default false, totalUnitsSharing default 1, ratioConfig JSON string stored, status ACTIVE
- **getMetersByProperty:** property belongs org, filter isDeleted
- **createReading:** meter belongs org, current>=previous validation, if previous null, fetch last reading top by readingDateDesc and use its current as previous, check current less than last recorded block, amount = (current-previous)*ratePerUnit, saves
- **getReadings:** by meterId pageable
- **createBill:** org, property, utilityType belong org, meter belongs org if provided, duplicate bill for property+utilityType+billingMonth blocked, billingMonth withDayOfMonth 1 normalized, totalAmount, dueDate, provider, billDocumentS3Key, status PENDING, saves, then **auto-split** if meter==null or isShared or meter.unit==null (master/building meter) → calls autoSplitBill
- **autoSplitBill:** fetches occupied units in property via unitRepository.findByOrganizationIdAndStatusAndPropertyIdAndIsDeletedFalse(orgId, OCCUPIED, propertyId), if empty warn no split. Parses ratios from meter.ratioConfig JSON via ObjectMapper: config type EQUAL → null (equal split), RATIO → ratios map unitNumber→Double, SUBMETER → not handled here (would need separate readings). Calculates totalRatio sum, unitRatios map unitId→ratio: if ratios provided use that, else equal split 1/n. If sum !=1 and RATIO, normalize ratios divide by totalRatio. Creates UtilityBillSplit per occupied unit: shareRatio, amountShare = totalAmount*ratio, unitsAllocated = totalUnitsConsumed*ratio if present, finds active tenant for unit via tenantRepository.findByUnitIdAndIsDeletedFalse filter ACTIVE, tenantId, unit, shareRatio, unitsAllocated, amountShare, calculationNotes "Auto-split ratio X from RATIO/EQUAL", saves. Sets bill status SPLIT, saves. Returns bill response with splits
- **autoSplitBill(Long orgId, Long billId):** overload for manual trigger, finds bill org check then calls private autoSplitBill
- **searchBills/getBill:** org check, presigned bill document
- **Mappers:** toTypeResponse, toMeterResponse, toReadingResponse with presigned photo 15m, unitsConsumed current-previous, toBillResponse with splits list and totalSplitAmount sum

**`SecurityDepositService`:**
- **createDepositForLease:** lease belongs org, deposit not exists for lease already, totalDeposited = lease.depositAmount, currency INR, status HELD, saves, initial ledger DEPOSIT amount = depositAmount balanceAfter = depositAmount
- **getDepositByLease/getDeposit:** org check
- **addLedgerEntry:** deposit belongs org, actor user exists, currentBalance = getCurrentBalance from last ledger entry balanceAfter else 0, switch transactionType:
  - DEPOSIT positive amount adds to balance
  - DEDUCTION/FORFEITURE positive amount required, check sufficient balance, newBalance = current - amount, ledger amount stored negative
  - REFUND positive amount required, check sufficient, newBalance = current - amount, ledger amount negative
  - ADJUSTMENT can be positive or negative, newBalance = current + amount
  - Creates ledger entry with description, balanceAfter newBalance, referenceType/Id (CONDITION_REPORT/TICKET/MANUAL), receiptS3Key, actor
  - Updates deposit status: balance 0 → REFUNDED or FORFEITED if type FORFEITURE, balance < totalDeposited → PARTIALLY_REFUNDED
  - Logs
- **getCurrentBalance:** last ledger balanceAfter else 0
- **toResponse:** ledgers orderByCreatedAtDesc, currentBalance = last balanceAfter else totalDeposited, ledger presigned receipt 15m

**`TransactionService`:**
- **createTransaction:** org, property/unit belong org if provided, invoice belongs org if provided, actor user exists, builds Transaction with type INCOME/EXPENSE, category, amount, date, description, paymentMethod, invoice/vendorPayout, ledgerReferenceType/Id, receiptS3Key, actor, saves, logs
- **searchTransactions:** org + propertyId/type/category/start/end date filters
- **getTransaction/delete:** org check, soft delete

**`TaxReportService`:**

### 6. Edge Cases & Business Rules

- **Invoice number:** unique INV-YYYY-XXXXX atomic counter + uniqueness loop
- **Proration mid-month move-in:** remainingDays/daysInMonth * rent, description "Prorated rent for MONTH YEAR (remaining/total days, move-in date)"
- **Proration move-out:** occupiedDays/daysInMonth * rent, move-out description
- **Auto-generation idempotent:** existsByLeaseAndPeriodAndType check skips if already exists for lease+month+RENT
- **Overpayment:** amountPaid > total allowed but logs warn, becomes credit for next invoice (future Phase 3 enhancement: auto-adjust next invoice)
- **Late fee:** finds applicable rule property-specific first then org-wide, effectiveDays = daysOverdue - gracePeriodDays, FIXED=amountValue, PERCENTAGE=total*rate%*days, SLAB=amount*days simplified, capped at maxCap, only applies if today>dueDate, line item LATE_FEE add or update, status→OVERDUE
- **Status state machine:** DRAFT→ISSUED/CANCELLED, ISSUED→PAID/PARTIALLY/OVERDUE/CANCELLED, PARTIALLY→PAID/OVERDUE/CANCELLED, OVERDUE→PAID/PARTIALLY/CANCELLED, terminal PAID/CANCELLED/VOID
- **Utility meterNumber unique**, ratioConfig JSON parsing via ObjectMapper, type EQUAL→equal split 1/n, RATIO→ratios map unitNumber→Double normalized to sum 1, SUBMETER future via separate readings
- **Reading:** current>=previous, previous from last reading if not provided, amount = (current-prev)*rate
- **Bill duplicate:** property+utilityType+billingMonth unique blocked, billingMonth normalized to 1st day
- **Auto-split:** fetches occupied units in property, ratios null→equal split, RATIO→unitNumber map, normalizes if sum!=1, finds active tenant per unit, creates splits shareRatio/amountShare/unitsAllocated, bill status PENDING→SPLIT, logs count
- **Deposit:** totalDeposited=lease.deposit, initial ledger DEPOSIT, currentBalance from last ledger balanceAfter, deduction/forfeiture/refund positive amount required but stored negative, insufficient balance check, ADJUSTMENT can be pos/neg, status update REFUNDED if balance 0 else PARTIALLY_REFUNDED or FORFEITED, ledger receipt presigned
- **Transaction:** property/unit belong org, invoice belongs org, actor exists, type INCOME/EXPENSE, category, receipt presigned
- **Tax report:** financialYear unique per org, start<=end, totals from transactions sumByOrgAndTypeAndDateBetween, reportJson summary with income/expense/netProfit, TODO PDF generation S3, 1-click logs income/expense/profit, presigned PDF
- **Scheduler:** monthly rent auto-generation 1st 8 AM IST, daily late fee 9 AM IST, finds overdue invoices ISSUED/PARTIALLY, applies late fee per invoice, logs counts
